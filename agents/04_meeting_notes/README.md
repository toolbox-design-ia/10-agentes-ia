# El acta perfecta — capitulo 7

decisiones, tareas) con el modelo local. El audio nunca sale de tu maquina.

Variables del .env: WHISPER_MODEL, OLLAMA_MODEL

Ejecutar: python agents/04_meeting_notes/agent.py reunion.mp3
El acta se guarda junto al audio como .acta.md
