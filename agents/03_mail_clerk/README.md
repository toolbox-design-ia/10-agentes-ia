# El secretario de correo — capitulo 6

Triaje IMAP en modo readonly (el servidor no marca nada como leido).
Clasifica los no leidos y puede dejar un BORRADOR en Drafts.
NUNCA envia correos: esa es la regla de oro del capitulo.

Variables del .env: IMAP_SERVER (o IMAP_HOST), IMAP_USER, IMAP_PASSWORD
(contrasena de aplicacion, no la de la cuenta — Anexo B)

Ejecutar: python run.py (opcion 3)  |  python agents/03_mail_clerk/agent.py
